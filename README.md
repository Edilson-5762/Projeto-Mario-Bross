## Sobre o projeto

Landing page desenvolvida durante o curso DevClub que reimagina Mario e Luigi como uma dupla de encanadores prestando serviço real: conserto de vazamentos, canos entupidos e torneiras pingando. A página tem um vídeo em loop como plano de fundo, um formulário de orçamento que desliza para o centro da tela via toggle de classes CSS, e um botão flutuante de WhatsApp com número e mensagem pré-preenchidos. Existe também uma segunda página (`servicos.html`) listando os serviços prestados.

## Funcionalidades

- Vídeo em background com máscara em gradiente para dar contraste ao texto
- Formulário de orçamento (nome, e-mail, problema) que abre/fecha em animação lateral, com envio via POST para Formcarry
- Máscara de fundo escurecida que fecha o formulário ao ser clicada
- Botão flutuante de contato direto via WhatsApp
- Layout 100% responsivo, com breakpoints dedicados para tablet (768px) e celular (480px)
- Navegação entre a página inicial e a página de serviços (`servicos.html`)
